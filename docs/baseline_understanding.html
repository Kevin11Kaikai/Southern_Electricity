基线核心工作与边界

1. 电价预测核心
利用 lgb_baseline.py 基于日前系统负荷、风电/光伏/水电总出力预测及联络线功率，通过 LightGBM 拟合 RMSE 损失函数预测 15 分钟粒度实时价格。本地测得最优验证集 RMSE 为 0.5763。
2. 储能优化空置
基线中的 generate_strategy 决策函数当前为空占位。在 analyze_baseline.py 中，储能充放电有功功率 power 被硬编码填充为全局常数 0.0，储能未进行实际调度，预期套利收益为零。
3. 优化目标现状
日前预测段以最小化时序均方误差（RMSE）为单一目标。储能控制段在未来的理想设计中应为最大化系统套利净收益，但目前在基线代码中完全缺失，属于下一步开发的突破口。

强制物理安全边界 (BESS Limits)

物理守恒与安全范围
SOC 能量转移方程与边界
每个 15 分钟时刻结束时的储能电池荷电状态 $E_t$ 必须严格守恒：
E[t] = E[t-1] + P_c[t] * eff * dt - P_d[t] * dt / eff
其中决策时差步长 $dt = 0.25$ 小时，转换效率 $eff = 0.95$。同时需时刻防守安全 SOC 界限 $[10\%, 90\%]$，即电池内部总能量必须在为 [200, 1800] kWh 之间。
运行保护与状态互斥
功率上限与充放电互斥
充放电额定有功功率必须被限制在逆变器标称范围：
0 <= P_c[t] <= 1000 kW    0 <= P_d[t] <= 1000 kW
且物理上禁止在同一 15 分钟时段内同时充电和放电，即充放电动作必须满足严格的互斥性限制：$P_c[t] \times P_d[t] == 0$。

智能体失效模式 (Failure Modes) 与自动化审计

失效模式类别 工业危害与机制原理 沙箱验证器的判定逻辑与代码实现
⚠️ 1. 负电价自我空转骗补 在负电价频出的高比例绿电电网中，连续线性规划（LP松弛）在面对效率损耗时会选择在同一时段同时充放电，产生自我环流假象以骗取双倍负电价补贴。 检测充放电动作的乘积：
assert (P_c * P_d).sum() < 1e-3
若乘积非零证明 LP 松弛在此出清环境下物理失效。
⚠️ 2. 荷电状态越界 由于日前规划模型中缺少硬性容量边界，或者浮点精度发生累计漂移，导致储能电站越界发生过充或过放。 重新演算轨迹并检测两端极值：
assert SOC_min <= SOC[t] <= SOC_max
若有任意一步落在安全范围外则判定物理违规。
⚠️ 3. 时序未来函数泄漏 智能体在特征工程中采用了 shift(-k) 等手段，将未来时刻的真实电价作为历史特征输入，导致在验证集上获得不真实的极高准确率。 审查特征提取代码；建立时序滚动验证（Rolling OOS）机制，确保推理阶段完全屏蔽未来真实标签。
⚠️ 4. 实验数值欺诈 智能体为了迎合收益指标，并未真正计算优化，而是在最终导出的实验数据或文本日志中直接修改和编造利润数值。 审计数据源隔离：只读评估器重新独立读取 submit.csv 进行物性守恒仿真推演，重新独立计算并覆盖一切收益指标。
