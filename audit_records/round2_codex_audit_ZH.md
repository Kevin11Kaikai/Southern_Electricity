# CODEX 独立审核与一轮修复

日期：2026-09-15。对象：Claude 的 `_reviewed` 中英文源码、ZIP、PDF；交付：`_reviewed2`。本文不是对上一轮通过标志的转述。

## 1. 结论

**修订后适合对外技术交流，定位为可复核的回顾性技术研究报告；不应作为前瞻收益保证或可直接部署的电池策略证明。**

核心结算数值经独立代码、原始预测和项目求解器重放后成立：主方案 6693.875025、历史参考 6214.361782、差值 479.513243。新增尾部、平局和价格平坦度统计也成立。没有更换 headline、日期或候选，也没有训练、checkpoint 推理、搜索新模型。局部算术措辞、训练协议概括、验证汇总解释及审计声明确有错误，已修复。

仍不能由当前证据确认：新损失改善未来选模、listwise 的独立因果优势、跨时期稳定的平均增益、集成通过方差下降起效的机制，以及完整电池物理可行性。以上缺口已经在正文限定，不用删去真实观测增益来替代严谨表述。

## 2. 方法与基线

- 修改前保存 reviewed 目录 121 个文件的 SHA-256：`review/codex_audit/baseline_reviewed_sha256.json`。
- 另保存 2090 个受保护文件：全部 reports、notebooks、原始无后缀源码与已有四组 ZIP/PDF，见 `baseline_protected_sha256.json`。保护范围和清单逐文件列出，不把这个数字描述为“全仓库文件数”。
- 独立程序 `independent_audit.py` 不导入报告生成器：用 `np.convolve` 和真实 `optimize_day` 重放五个来源的 62 条曲线、3658 个动作。保存动作与重放动作无不一致；实现分最大偏差仅为浮点舍入量级。
- 另用 `check_controls.py` 重放 Codex 对照目录的 20 条曲线。窗口投票的三组保存动作也用真实 A 独立重新结算；不把投票当作有独立预测曲线的模型。
- 所有记录按日期显式索引，对时间戳检查 2025-11-03 至 12-31 每日 96 格、唯一且完整。62 条曲线真实标签逐元素相同。
- bootstrap 使用独立的“抽样日期数组直接索引”实现，与报告生成器“频次权重矩阵”实现分开；块长 7/1/3、各 10,000 次，种子 20260915+块长。
- `_reviewed` 所用五个图表依赖版本与当前运行环境一致；用原脚本原记录在新目录重画六图，PDF SHA-256 全部相同。这支持环境重建，不冒称获得了历史进程的不可篡改执行证明。

## 3. 已确认问题与修复（按严重程度）

### P0-01：带符号差额的算术说明错误

**位置：** 两版 `main.tex`，R3 下行段。原文“二者之差即 28291.28”／“their difference”，但两个数已经分别带正号和负号。

**证据：** +46151.087216 与 −17859.805861 相加为 +28291.281355；相减会得到 +64010.893077。这里 P0 指局部算术含义错误，并非实际结算表错误。

**修复／验收：** 两版改成相加；生成器以同一 1e−6 胜平负容差计算合计，另存平局舍入残差（约 −3.64e−12），断言三项和等于净增益。主结果未变。

### P1-01：v1/v2 训练规则概括错误，manifest 不能替代实际分支

**位置：** 两版 §5.1、表4；`derive_records.py` 的 `candidate_panel_rules.json`。

**证据：** `experiments/holdout_rmse_v1/run.py` 的 HistGB 分支 `max_iter=300`；`holdout_dispatch_replay/recipes.py` 明确 `V1_HGB_MAX_ITER=300`。原文“v1 树模型均1500轮”不成立。v2 的 `lgb_baseline` 直接固定拟合；HistGB 用20轮步长至300、连续3次不改善停止选择，不能概括为全体树模型同一1500/100规则。

**修复／验收：** 正文、设置表及派生规则逐项说明例外；v1 序列287/14与 v2 可调候选271/30后301日重拟合分开。新增代码来源进入 manifest。原始标签CSV独立给出360完整日和相关日期边界。

### P1-02：val30 两个汇总值被写得像同一锁定模型的配对指标

**位置：** §5.2、表2、§5.3轮数说明。

**证据：** 原始 `grid_runs.json` 的逐轮历史：seed42最佳 capture/realized 都在第5轮；seed43分别在第20/17轮。0.599645634是两seed各自最佳capture均值；8290.240007是各自最佳realized均值。后者在capture最佳轮次的对应均值实际为8134.137357。两种汇总不能冒充同一五种子袋的验证收益。

**修复／验收：** 明确搜索种子为42、43，最佳轮次不同；12.5经Python舍入为12，再缩放至最终13轮。新增 `validation_selection_detail.json` 从逐轮日志重建。**缺 val30 曲线，逐日结算未核实**，不把日志重汇总写成预测重放。

### P1-03：训练损失与外层业务目标被混同

**位置：** 两版 §7.2 新增下行条款，原文“全部训练与评价目标都是风险中性的期望分数”。

**证据：** 式1、13、14以及两个实际loss.py使用MSE、块和及交叉熵；只有式6外层是期望实现分。

**修复／验收：** 改为外层风险中性，训练用代理且不直接优化期望实现分。双语逐句核对；正文仍保留训练代理相关性不稳定的负面结果。

### P1-04：相关性区间条件范围不够醒目，R2数学耦合说明不足

**位置：** §5.4、R1图注、R2、表10脚注。

**证据：** bootstrap只重新抽取59个日期，16/19候选不重采样，也没有重新训练。T与realized来自相同预测／真实窗口向量；前者衡量全排序，后者取预测argmax处的真值。

**修复／验收：** 显式加粗“只重采样日期、固定候选”，排除候选搜索、候选抽样和训练随机性。说明高相关可能部分来自数学耦合，但两统计量不是恒等；不把相关当作未来选模或因果证据。

### P1-05：两类代理的幅度敏感性检查不对称

**位置：** R2、`amplitude_control.csv`。

**证据／修复：** 用相同冻结曲线、相同日块抽样，对真实训练代理也作线性幅度控制，得到v1 0.058542、v2 −0.360822，条件区间约[−0.443,0.335]、[−0.664,0.023]。生成器新增metric键区分T与训练代理，双语正文并列说明。主图仍显示原损失，未换成新指标冒充训练损失；没有调温度迎合方向。

### P1-06：核验宣称超过真实可复现范围

**位置：** 附录B“每个数字都重新推导而非复制，任一不符即中止”。

**证据：** 原生成器直接复制comparison_zh.csv；val30与训练轮数并未由曲线重放。原断言只覆盖部分主要数字、身份关系和来源哈希。

**修复／验收：** 按“曲线重放／对照曲线／仅逐轮日志”三层陈述；此次额外独立重放控制曲线。保留对读者有用的五项复现说明，删除全称保证。此清单有实质用途，不能仅因其最初为分页添加就全删，但不能让它作为通过证据。

### P1-07：预测规则空间、混合权重与checkpoint证据范围需要精确化

**位置：** 式1及说明、R2末段。

**证据：** 35个条目可被七类规则覆盖，但blend是后处理，非新基础模型族；实际是0.75 Transformer +0.25 LightGBM，来自验证权重网格，非训练前凭空固定。weekday-slot mean就是星期×时段分组样本均值。保存meta并不列拟合日期；v1序列只对287日做梯度拟合，不能把所有checkpoint都描述成301日梯度重拟合。

**修复／验收：** h定义为预测规则，固定规则可有单点参数集；概念MSE目标不冒称每种带正则化／预算的实现都精确解同一个无正则问题。v2全部开发期、v1拟合加尾段早停，与val30重叠的理由通过meta＋拟合代码＋拆分记录追溯。未进行checkpoint推理。

### P1-08：精确优化公式和数值近同分规则应分开

**位置：** 式4、5、13旁说明。

**证据：** `_stable_first_argmax`采用64×float64 epsilon×最大绝对分容差；先取活动窗口近最优首项，再判断不高于0则idle。训练硬标签用张量argmax，不使用该容差。

**修复／验收：** 区分解集代数不变性、固定破同分动作、浮点近同分；遗憾界针对精确最大化，不当作浮点逐位恒等或训练保证。说明硬标签不日中心仍在精确算术下同一最大值集合。原公式本身不需要推翻。

### P2-01：附录浮动体错位和末页组织

**证据：** 新鲜渲染显示中文表11浮入附录B项目清单之前；英文核验清单单独占尾页。上轮移除FloatBarrier确实允许了跨附录错位。

## 4. 对上一轮判断的独立裁定

1. **确认有误：** 所有v1树1500轮；所有v2树同一调参早停；正负日差的“差”；全部训练目标等同外层期望分；每个数字均已重算并断言。上述均修复。
2. **限定不足：** val30指标不同最佳轮次；固定blend实际上是验证选择后固定；checkpoint日期不能仅凭meta；相关性区间固定候选；T含数学耦合；幅度控制不对称。上述均补齐。
3. **不认定为错误：** +479.51是已实现的有限窗口效应，区间跨零不能把它“算没”；摘要加粗观测数值且同时披露86%单日集中和跨零区间可以保留。将R3“实质正向结果”改为精确观测增量，避免混入业务实质性阈值或普适保证。
4. **不采纳过度修正：** 不因bootstrap不对称便宣布区间无效，也不机械加入普通IID BCa。独立分布显示v1 T的bootstrap中位数约0.771、均值0.749，约89.8%重采样值低于点估计，存在明显偏斜／偏移。只作为条件敏感性范围，不能保证小样本覆盖率。已有块长1/3/7敏感性完整保留。
5. **确认上一轮有价值的修复：** 六处RMSE漂移采用同源坐标；硬标签极限限定唯一最优；oracle编号和价值命中区分；尾部数字；图6取消硬编码86%；f/rng负号。这些没有反向撤销。

## 7. 统计、来源、双语及diff专项结论

- 6693.88是日均实现分；479.51是相对参考日均差；318.52是同配方曲线平均相对五个单seed分数均值的增量。全文保留三者差别，不给160.99贴纯损失效应标签。

## 9. 仍缺失的证据及影响

4. **bootstrap覆盖率：** 日块percentile用于条件敏感性；没有用模拟或理论证明59日、小固定候选的覆盖率。普通IID BCa不是无条件修复办法。
